## Featured Project

### Pokémon Emerald Randomizer
C++ tool for modifying Pokémon Emerald ROM data to randomize Pokémon encounters, with plans to support additional game data in the future!

The project involved reverse engineering the ROM to identify specific ROM offsets that contain particular Pokémon data, which can then be modified programmatically!

[View Repository](https://github.com/skskskye/pokemon-emerald-randomizer)
